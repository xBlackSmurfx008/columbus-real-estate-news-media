# Columbus Real Estate News Media Company

Website-first launch implementation for a Columbus real estate and lifestyle media platform.

## What is included

- Static website MVP with required pages and subscription flow
- Area/topic taxonomy and editorial standards
- First-party analytics and consent framework
- 30-day content slate and starter post drafts
- Monetization assets (media kit, rates, ad inventory, founding package)
- Outreach cadence and discovery call tracker/templates

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

Example with Python:

`python3 -m http.server 8080`

Then open `http://localhost:8080`.
